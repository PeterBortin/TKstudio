# Творча кухня — адмінка мережі студій

Відкрийте index.html у браузері (Chrome, Safari, Firefox, Edge).
Найкраще — з локального сервера, бо браузери блокують частину запитів для file://:

    cd <ця папка>
    python3 -m http.server 8080
    # відкрийте http://localhost:8080

## Що всередині

    index.html   застосунок (усі екрани, ролі, дані)
    support.js   рантайм рендерингу
    ds-base.js   підключення дизайн-системи
    _ds/         токени й компоненти Vektr Design System
    assets/logo  логотип «Творча кухня»

Фото майстер-класів підтягуються з tkstudio.com.ua, тому для них потрібен інтернет.
Шрифт Inter — з Google Fonts.
