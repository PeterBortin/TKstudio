# Творча кухня — адмінка мережі студій

## Локально

    cd <ця папка>
    python3 -m http.server 8080
    # http://localhost:8080

## GitHub Pages

Залийте вміст цієї папки в корінь репозиторію (або в /docs) і ввімкніть Pages.
Файл .nojekyll обов'язково має поїхати разом — без нього Jekyll ріже частину файлів.
Папки навмисно без підкреслення на початку (ds/, а не _ds/) саме через це.

## Структура

    index.html      застосунок: усі екрани, ролі, дані
    support.js      рантайм рендерингу
    ds-base.js      підключення дизайн-системи (шляхи відносні до себе)
    ds/vektr/       токени й компоненти Vektr Design System
    assets/logo/    логотип «Творча кухня»
    .nojekyll       щоб GitHub Pages віддавав усі файли як є

Фото майстер-класів підтягуються з tkstudio.com.ua, шрифт Inter — з Google Fonts:
для них потрібен інтернет. Решта працює офлайн.

## Ролі та студії

меню й доступні розділи змінюються під роль. Перемикач ліворуч — «Усі студії»
(мережевий рівень), 7 локацій та онлайн.
