# Творча кухня — адмінка мережі студій

Один файл: index.html. Нічого більше не потрібно — усі стилі, компоненти,
рантайм і логотип уже всередині.

## GitHub Pages

1. Закиньте index.html (і .nojekyll) у корінь репозиторію.
2. Settings → Pages → Deploy from a branch → main / (root).
3. Готово: https://<user>.github.io/<repo>/

## Локально

Просто відкрийте index.html подвійним кліком — працює і з file://.

## Що потребує інтернету

Фото майстер-класів (tkstudio.com.ua) і шрифт Inter (Google Fonts).
Решта — офлайн.

## Ролі та студії

Аватар у правому верхньому куті — власник, директор мережі, адміністратор,
художник: меню й доступні розділи змінюються під роль. Перемикач ліворуч —
«Усі студії» (мережевий рівень), 7 локацій та онлайн.
